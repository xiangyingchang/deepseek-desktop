## Failure classification

- `lock-proof-web`: DSH Stack found a portable frozen source, but the third-party bundle fails during Cordis activation because its runtime entry reads `tools` without declaring the required injection. This is a third-party Profile bug, not a reason to add a case-specific adapter.
- `bundle-updater-web`: Preflight now catches a missing build artifact before Freeze. The actionable repair is to publish/pin a built package or make a reproducible prepare step available.
- `dshr` and `DeepSeek-TUI`: local/workspace links are explicitly unsupported; the pipeline does not rewrite them into fake registry dependencies.
- `netcafe-base-only`: the Profile is portable, but it is not a Web Profile. The Web Client pipeline refuses to boot the default `web` Profile as a hidden fallback.

## Remaining gate

These are Packaging/Runtime results, not Live Agent or clean-machine results. A non-official Profile still needs an independent machine, tester-entered API key, and a real Agent turn before Phase 2 can be called fully complete.
