# Reference Distribution UAT

This is a manual black-box test. The tester must not be the implementer and must use a Mac without the frozen Profile preconfigured.

## Artifact under test

- Stack: `examples/reference`
- Client: generated by `dsh-stack package examples/reference`
- Required secret: `DEEPSEEK_API_KEY`
- Runtime UI: the official DeepSeek Harness Web UI, opened by the thin native shell

## Preconditions

- Download the `.app` from the package output and copy it to `/Applications`.
- Do not install Node, pnpm, DSH CLI, or the Profile.
- Do not run a Terminal command during the test.
- Have a valid DeepSeek API key available to enter into the first-launch prompt.

## Test steps

1. Double-click the installed `DSH Stack Reference.app`.
2. Enter the required API key in the native first-launch prompt.
3. Confirm the key is stored in macOS Keychain rather than a plaintext artifact file.
4. Confirm the official Harness Web UI opens in the default browser.
5. Create one Web session and complete one real Agent turn.
6. Quit and relaunch the app.
7. Confirm the private runtime/Profile is reused and the official UI opens again without Node/pnpm/CLI installation.
